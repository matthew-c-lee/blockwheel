# Wooden signs

Ordinary wooden signs are available by default in wooden plank families. They occupy the bottom-left of the wheel. Existing block, stair, slab, fence, log, wood and trapdoor positions stay fixed; all eight standard wooden options fit together.

## Material values

Minecraft 26.2 crafts six planks and one stick into three signs. Ignoring the stick, Blockwheel therefore uses **one sign = two planks**. A sign is four material units, versus two for a plank and one for a slab.

| Conversion | Result |
| --- | --- |
| Six planks → signs | Three signs |
| One sign → planks | Two planks |
| One sign → slabs | Four slabs |
| One log → signs, experimental wood enabled | Two signs |
| Two signs → log or wood, experimental wood enabled | One log or wood |
| 64 planks → signs, experimental wood disabled | Sixteen held signs and 32 stored planks |

Signs use their native **16-item stack limit**. The existing one-stack output policy applies, with exact physical leftovers. Sticks are neither required nor generated by these conversions. All twelve vanilla wood types are supported, including bamboo and the crimson/warped types.

## Optional inventory features

Builder Mode off keeps simple held conversions and minimal matching-source batch completion. Builder Mode on can consolidate compatible main-inventory material into the held sign stack. Restocking, pick block, Shulker Supply and named-template filling use the same family and units; their existing source, capacity and protected-slot rules remain unchanged.

Automatic storage still prefers logs, then planks. Signs are an available building shape rather than a preferred leftover storage form. One sign can normalize to two planks; two signs are one complete log batch. Three signs stay six planks when a log/remainder split would add clutter.

Written or otherwise customized sign stacks are not converted: item components, including block-entity data, are protected by the existing ordinary-stack checks. Hanging signs use stripped logs and chains, so they remain outside these transformations. Stripped logs/wood and shelves also remain excluded.

## Modded wood types

The built-in [sign definition](../src/main/resources/data/blockwheel/blockwheel/shapes/sign.json) uses `minecraft:standing_signs` and requires an inferred base tagged `minecraft:planks`. An unambiguous shaped recipe identifies the species. Matching new wooden types can be discovered without Java changes. Irregular recipes, tags or material values can use explicit data-pack definitions; see [EXTENDING.md](EXTENDING.md).
